## 品牌底层思想的抽象解构

本次重构彻底抛弃了早期“具象盾牌”以及“罗盘+楼梯”等机械化的具象拼凑，遵循当代顶级数字产品（Apple Design Award / Linear / Oura / Opal 水准）的设计语言，对 **KairosStep (人生阶跃)** 的底层哲学进行抽象化重塑：

```
                          ┌───────────────────────┐
                          │  Kairos: 觉醒与破晓金芒  │
                          └───────────┬───────────┘
                                      │
                   ┌──────────────────▼──────────────────┐
                   │    Ascending Helical Elevation      │
                   │    (升阶螺旋曲面 · 生命轨迹跃升)      │
                   └──────────────────┬──────────────────┘
                                      │
                          ┌───────────▼───────────┐
                          │  Step: 稳健基座与生活防线 │
                          └───────────────────────┘
```

### 1. 概念意象解构
- **Kairos（关键时机 / 顿悟契机）**：
  在日复一日的平庸时流中，总有关键时刻需要清醒决断。曲面最高峰捕获那一抹温暖醇厚的**破晓金光（Dawn Gold Edge）**，象征在生命节点被点亮的明智决策与笃定认知。
- **Step（相变跃迁 / 阶跃轨迹）**：
  不画呆板的物理台阶，而是用一条**优雅连续升阶的立体螺旋曲面（Helical Elevation）**表达生命的非线性阶跃。自稳固的基座自下而上盘旋升维，暗合 90 天周期培养法中的微动作沉淀与生活维度的全面升阶。
- **触感微光与材质语言（Tactile Materiality）**：
  - **主体材质**：温润哑光骨瓷/暖纸陶瓷肌理（Warm Matte Porcelain），呼应全应用“温暖纸感人生指南”的人文温度，温和、沉稳、无压迫感。
  - **光影与暗部**：曲面内凹转折处泛着极克制的深邃夜幕蓝（Action Blue #2A72DE）微漫反射，在纯黑曜岩（Obsidian Charcoal #12151B）底色上自然悬浮，层次极具呼吸感。

## 适配规格与安全区

- **主母图规格**：`1024×1024` 正方形，100% 不透明纯色背景（无预圆角，完全交由操作系统遮罩裁剪）。
- **几何中心与安全边距**：
  - 视觉主体水平几何中心为严格正中（`X = 512.0`），左右安全边距各 `293px`（约 28.6%）。
  - 垂直边距各留出 `208px~212px`（约 20.5%）。
  - 整体紧密贴合 Android Adaptive Icon 的 **66% 核心安全圆** 与 iOS Squircle 规范，在极端裁切下主体饱满舒展、无任何断角，且在 `48px` / `32px` 极小尺寸下依然具有极高的轮廓辨识度。

## 全平台自动导出与一致性核验

从仓库根目录执行（Python 3 + Pillow）：

```bash
python3 tools/export_app_icons.py
python3 tools/export_app_icons.py --check
```

- **Android**：覆盖全部 5 级分辨率 mipmap 资源（`mdpi 48px`、`hdpi 72px`、`xhdpi 96px`、`xxhdpi 144px`、`xxxhdpi 192px`）。
- **iOS / macOS**：依据 `Contents.json` 自动缩放并覆盖 16px 至 1024px 全阵列尺寸。
- **Web**：更新 `favicon.png` (32px)、`Icon-192`、`Icon-512` 以及 `maskable` 规范图标。
- **Windows**：导出包含 16/24/32/48/64/128/256 像素全尺寸帧位的 `app_icon.ico`。
