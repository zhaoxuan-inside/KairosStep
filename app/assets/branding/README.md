# KairosStep 应用图标

更新日期：2026-10-28。

## 品牌理念与设计含义

为解决早期“深蓝背景 + 翠绿盾形”过于偏向杀毒/安全卫士类工具、与产品人文理念脱节的问题，全新图标严格围绕产品名称 **KairosStep (人生阶跃)** 及《产品设计文档》中“767条人生建议与决策助手”的核心意象重新设计：

1. **Kairos（时机与决策罗盘）**：希腊语 Kairos 意为决定性、关键性的至优时机。顶部金色八角星罗盘（Kairos Apex）象征在人生重大节点（教育、求职、婚恋、医疗、法律、养老）做出的明智抉择与方向锚点。
2. **Step（拾级而上的阶跃）**：下部几何阶梯（Ascending Steps）象征 90 天周期培养与生活阶梯式稳步前行，告别一次性灌输，一步步筑牢安全与认知底线。
3. **色彩与质感规范**：
   - 沉稳内敛的深邃夜空墨石底色（#181B22），100% 不透明纯色背景，与移动端桌面完美融合。
   - 暖金（#D4A759）罗盘与阶梯外缘 + 典雅暖纸白（#F7F1E8）核心阶跃路径，呼应全应用“温暖纸感人生指南”的视觉设计语言。
   - 嵌入行动蓝（Action Blue #2A72DE）微三角细节，象征关键时刻的执行力。
4. **适配规格与安全区**：
   - 主文件尺寸：`1024×1024` 正方形，高保真无损色彩。
   - 视觉主体尺寸约为 `532×529`（居中占比约 52%），四周留白均在 24% 以上，完全收敛在 Android 自适应图标与 iOS Squircle 的 60%~66% 核心安全区内，圆角或圆形遮罩裁切后依然饱满舒展，在 48px / 32px 极端缩放尺寸下仍具有出色的识别度。

## 导出与核验

从仓库根运行（Python 3，依赖 Pillow）：

```bash
python3 tools/export_app_icons.py
python3 tools/export_app_icons.py --check
```

- **Android**：覆盖 5 个 mipmap 密度（mdpi 48px、hdpi 72px、xhdpi 96px、xxhdpi 144px、xxxhdpi 192px）。
- **iOS / macOS**：依据各自 `Contents.json` 自动缩放并精确覆盖所有点阵规格。
- **Web**：覆盖 favicon (32px)、Icon-192、Icon-512 以及 maskable 图标。
- **Windows**：输出包含 16/24/32/48/64/128/256 像素全帧位的 `app_icon.ico`。
