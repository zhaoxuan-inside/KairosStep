四 · 工程落法

Flutter 侧定义统一的 WindowCardData（锚点日 / 窗口天数 / 防线项与建议日 / 确认集）与 WindowCardStyle 枚举；本章 A-F 与模型 1-4 各是一个纯渲染器注册进 InteractionStyleRegistry，卡片长按或设置页切换样式，全部渲染器共享确认集、完成豁免期与提醒解除状态——新增方向即新增一个渲染器，零侵入。本章第三节的八类提取交互对应现有代码：cards/interactors.dart（连击/快速打卡/红线/防线/分步）、cards/advice_card.dart（豁免沉底/翻转）、review/carnegie_review_sheet.dart（4 步向导）、now/now_view.dart（时间尺）。
