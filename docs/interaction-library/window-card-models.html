窗口期四种交互模型的可操作流程演示：单步承诺、检查点响应、倒排计划、布防状态机。每个模型都可实际走完流程。

四种模型的差异不在外观，而在交互规则本身——同一时间承诺几件事、完成由谁触发、错过怎么办。

模型 1 · 单步承诺（同屏只有一个活动任务）

系统每次只提议一步；你接受后才成为活动任务，完成即自动递补下一项。认知负担恒定为一。

活动任务 0/4

模型 2 · 检查点响应（到点必须应答，漏检升级）

D3/D7/D10 三个检查点到点弹出应答；未响应记漏检一次、提醒加密——交互是“应答”而不是“浏览清单”。

模拟时钟 D3
漏检 0 次 · 提醒常规

模型 3 · 倒排计划（从真实截止日反推三个阶段）

你只输入一个真实截止日，系统倒排出三段计划；落后时提示自动收紧——交互是“约定计划并追平”。

真实截止日 模拟今天：D5

模型 4 · 布防状态机（布防 / 暂停 / 收网 / 解除）

整张卡是一个安防面板：四种布防状态由你显式切换，提醒节奏与卡面随状态整体变化。
