# 标签有效性分析（token 级）

对象：`HowToLiveBetterBrief.md` 767 条建议的 286 个标签 token。
视角：信息检索/NLP 指标 —— 文档频率 DF、信息量 `log2(N/DF)` bit、上位词覆盖（语义宽度）、标注一致性（默认值坍缩）、与结构字段（章节）的相关性。
工具：`tools/tag_effectiveness.py`，可复跑。
（上一篇 `TagSystemAnalysis.md` 是维度级分析——组合唯一性；本篇下沉到单个标签。）

## 总体画像

286 个 token 的 DF 分布：

| DF 带 | 数量 | 占词表 | 判定 |
|---|---|---|---|
| ≥400（DF≥52%） | 12 | 4.2% | 近常量，无区分力（判据 2 的无效标签） |
| 100–399 | 19 | 6.6% | 偏宽，需看语义是否单一 |
| 20–99 | 57 | 19.9% | **健康带** |
| 5–19 | 29 | 10.1% | **健康带** |
| 2–4 | 12 | 4.2% | 过窄，聚合价值低 |
| =1 | 157 | 54.9% | 幽灵标签，已退化为关键词 |

**只有约 1/3 的词表在真正承担标签职能**；两端各有一类失效：太宽（无区分）和太窄（无聚合）。

## 一、无效标签（判据 2：全库/绝大多数都有）

**DF = N（0.00 bit，彻底无效）**：`#自身`（767/767，关系角色）。

**DF ≥ 40%（0.06–1.03 bit，接近无效）** 共 13 个：

| token | 维度 | DF | 占比 |
|---|---|---|---|
| 长期有效 | 时效 | 737 | 96.1% |
| 中年 / 青年 | 人生阶段 | 656 / 653 | 85.5% / 85.1% |
| 通用 | 适用群体 | 635 | 82.8% |
| 泛指 | 动作对象 | 612 | 79.8% |
| 不涉及钱 | 涉金 | 589 | 76.8% |
| 可独立完成 | 依赖 | 575 | 75.0% |
| 全民 | 社会角色 | 502 | 65.4% |
| 事前 | 时机 | 501 | 65.3% |
| 不限场景 | 场景 | 442 | 57.6% |
| 老年 | 人生阶段 | 409 | 53.3% |
| 情境触发 | 触发 | 375 | 48.9% |

其中 中年/青年/老年 的宽泛是**语料属性**（多数建议本就面向成年人），修复方式不是拆词，而是承认受众维不承担定位（见维度级报告）。其余 9 个全部是**默认值/负定义 token**（见第四节），修复方式是把"默认"从词表里降级。

## 二、反向无效：幽灵标签（DF=1，标签关键词化）

157 个 token（占词表 54.9%）只挂在一 条建议上：动作对象的 155 个具体值（#安全带、#含糖饮料、#槟榔…）+ #男性(2)、#超重(2)、#AI(2)、#在夜里(2)、#创作者(2)、#房东(2)、#饮食(3)、#定期(3) 等。

按判据 1（语义单一、够窄）它们是"好标签"，但作为**标签**已失效：DF=1 意味着没有共现结构、不能聚合浏览、不能交叉过滤——它和标题首词没有区别，职能上是全文检索的关键词，不是分类法的槽位。标签有效性的带宽是双向约束：**太宽无区分，太窄无聚合**，健康带约 DF∈[5, 300]。

## 三、语义过宽的实证（判据 1）

1. **#学生**（社会角色，21 条）：人生阶段分布横跨 6 种组合——从 `#少年`（中小学生）到 `#青年 #中年`（在职读研？），正是"覆盖小学生到大学生"的例子；且 71% 集中在节 23（学什么技能），更像章节别名。而词表里已有它的一个下位词 `#留学生`（12 条）单列——**父词在词表、子词也在词表、粒度不一致**。
2. **类别伞形标签的粒度三态并存**（同一语义槽三种标法）：
   - `#健康`：仅父 110 条 ｜ 父+子 44 条 ｜ 仅子 137 条（用药 62/急救 50/筛查 29/医疗 29/运动 14/慢性病 14/疫苗 13/睡眠 12…）
   - `#安全`：仅父 84 ｜ 父+子 18 ｜ 仅子 25（防骗 36/网络安全 12/居家安全 7）
   - `#家庭`：仅父 10 ｜ 父+子 45 ｜ 仅子 70（育儿 49/婚恋 36/生育…）
   直接后果是**召回损失可量化**：搜 `#健康` 命中 154 条，但 137 条只标了子词的建议被漏掉——标签粒度不统一比没有子标签更糟。
3. **#收藏**（显示方式，303 条 = 39.5%）：散布在全部 34 个节，混装法律红线（后果对照）、医疗误区（官方说法对照）、理财原则（决策启发）、认知偏差（观念卡）——一个标签绑四种组件形态，是显示方式维度的"兜底伞"。
4. **#情境触发**（375 条，48.9%）：触发维度的 else 分支，"与日常动作相伴"吞掉了从系安全带到刷牙的一切习惯动作；与 `#偶发`（289 条）共同构成两大兜底，155 条两者兼备。
5. 同层近义对继续分裂区分力：职场 52/职业 42、理财 113/消费 35/省钱 15、法律 217/防骗 36、安全 102/居家安全 7/网络安全 12——同一个概念的名义 DF 被拆成 2–3 份，每个都掉出健康带。

## 四、负定义 token：词表里的"else"不是标签

8 个高频 token 的定义是"没有某特征"而非"具有某特征"：`#自身`(100%)、`#通用`(83%)、`#泛指`(80%)、`#不涉及钱`(77%)、`#全民`(65%)、`#不限场景`(58%)、`#偶发`(38%，定义"无固定节奏")、`#定期`(0.4%，定义"周期不明确")。

NLP 后果：① 它们占据语料主体，把所在维度的 DF 分布压成单峰（判据 2 失效的直接来源）；② 正向值与缺省值同级混居，导致**缺失语义不明**——没标 `#女性` 究竟是"不限性别"还是"没查"？标注一致性被默认值破坏。

## 五、有效性杀手：章节别名（与结构字段冗余）

受众维 17 个 token 在单一章节的集中度 ≥70%（9 个为 100%）：

| token | DF | 集中章节（占比） |
|---|---|---|
| 经济困难 | 23 | 节7（100%） |
| 合伙人 / 陌生人 / 军人 / 留学生 / 出境者 / 家有老人 / 残障人士 / 租房人 | 5–48 | 节12/13/31/32/21/17/33/15（各 100%） |
| 购房人 | 11 | 节15（91%） |
| 孕产 / 准父母 | 各25 | 节27（80%） |
| 吸烟者 | 5 | 节2（80%） |
| 父母 | 17 | 节17（76%） |
| 学生 / 照护者 / 确诊慢病 | 21/24/20 | 节23/20/16（71–70%） |

这些标签与章节字段近似一一映射（互信息≈1），是章节结构的**改名副本**，对检索/剪枝的增量信息≈0。它们存在的真实原因：打标是按节批量做的，标签继承了章节边界。判断标准：一个标签的取值若能从结构字段预测，就不是有效标签。

## 六、"好标签"被路由不一致饿死（以 #女性 为例）

`女性/男性` 正是"语义单一的好标签"的样本，但实测 `#女性` DF 只有 6：

- 标题含女性特征的条目 20 条，仅 6 条标了 `#女性`（HPV、乳腺癌、宫颈癌、骨密度、潮热、痛经）；
- 其余 14 条（27 节孕期全节、18-3 孕期劳动保护、34-5 孕期用药等）的性别语义全部走了**人生阶段 `#孕产`** 而不是适用群体 `#女性`；
- 男性 2/2 标注齐全（样本少）。

即"性别特异"这一语义在两个维度间路由不一致：查 `#女性` 会漏掉全部 14 条孕产内容，除非用户知道还要叠加 `#孕产`。**标签本身有效，分配路径不一致使其失效**——这是比词表设计更隐蔽的有效性损耗。

## 七、死词

声明词表中 DF=0：关系角色的 `#上级`、`#下级`、`#朋友`——从未使用，应删除或落实。

## 修复清单（按性价比排序）

1. **默认值降级**：通用/不限场景/泛指/全民/不涉及钱/自身/长期有效 改为"不标即默认"（例外标注法），词表只留正向值。一步消灭判据 2 的全部 9 个近常量 token，顺带修复缺失语义不明问题。
2. **统一粒度口径**：类别树化后执行"只标叶子、父级自动继承"（或"父+最具体的子"二选一，全库一致）；健康/安全/家庭三个伞的 137+25+70 条"仅子"条目补父，110+84+10 条"仅父"条目补子。
3. **删除章节别名标签**：上表 17 个 token 改由「章节→画像」映射规则在渲染时动态生成，不占标签位；确有跨节语义的（如 吸烟者、确诊慢病）保留但按内容重新核定，不按节批打。
4. **性别语义统一路由**：孕产类条目同时补 `#女性`（或规定"孕产⊂女性，检索时自动展开"），把 `#女性` 的 DF 从 6 恢复到应有的 ~20。
5. **动作对象 DF=1 的 155 个 token 迁入搜索索引**：保留其"保唯一"职能（维度级报告已确认），但不再计入标签词表统计，避免 55% 的幽灵占比污染词表治理。
6. **同义对合并落地**：职场/职业、消费+省钱/理财、居家安全+网络安全+防骗/安全 按声明执行。
7. 词表新增标签设**准入带宽**：DF<5 不入词表（进搜索索引），并在每次内容变更后用脚本复查 DF 漂移。
