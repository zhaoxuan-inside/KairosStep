# KairosStep 业务测试用例（E2E · 模拟器）

> 依据业务模块与数据分层设计（画像引导 → 当下/今天/周期 → 指南 → 我的 → 紧急 → 持久化）。
> 执行方式：`integration_test/e2e_test.dart` 于 Android 模拟器实机运行（真 SharedPreferences + 真插件），
> 外加发布包冒烟：安装 release APK 冷启动无崩溃。
> 断言锚点：UI 文本（zh_CN）、少量 ValueKey（`todo-toggle-*` / `todo-remove-*` / `ok` / `topic-*`）。

## 风险与已知约束

- 「长辈模式」并非独立功能：产品上只有「和长辈相关的建议」——指南页范围三态
  （画像专属/父母适用/全量 737）与画像中的孝亲/育儿标签。store 层遗留的
  `kSeniorMode` 键无任何 UI 入口与消费点，属死代码（不阻塞发布，待清理）。
- 通知投递双路径（REFACTOR_DESIGN §5.4）：提醒到点 → 应用内提醒对话框
  （前台，不可忽略，立即打卡/稍后）；主动探查 → 系统通知
  （9:30/14:15/20:00 档，zonedSchedule 闹钟，点击通知进入探查弹窗）。
- 语义检索依赖随包 ONNX 模型（arm64 原生库），x86_64 模拟器上走词法兜底
  （已验证兜底路径无崩溃）；arm64 真机语义通道逻辑由单测覆盖。
- 1.5h 视窗与探查窗口随真实挂钟变化，相关断言已做时段兼容。
